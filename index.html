02 / A little about me

Design with intent. Code with care.

The person behind the work

I'm Abdul Rehman, a Web Developer who cares as much about how a page feels as how it looks.

My work combines HTML, CSS, JavaScript, Tailwind CSS and React with attention to typography, layout and motion. I aim for clear navigation, considered details and an experience that holds together on any screen.

I build business websites for restaurants, real estate agencies and dental clinics, plus tools like Zon and Motionpix. Every site is mobile-first, quick to load and built with clean, SEO-friendly code.

Based in Pakistan, working with international clients on WhatsApp.
